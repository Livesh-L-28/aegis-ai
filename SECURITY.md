# Security Policy — LogicFalcon (powered by AEGIS AI)

The LogicFalcon team takes the security of our platform and its users seriously. We appreciate the efforts of security researchers and community members who report vulnerabilities to us in a responsible manner.

---

## Supported Versions

Only the latest release receives active security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

**Please DO NOT file public GitHub issues for suspected security vulnerabilities.**

To report a potential vulnerability:
Please use **GitHub Private Vulnerability Reporting**:
Navigate to the repository on GitHub ([Livesh-L-28/logicfalcon](https://github.com/Livesh-L-28/logicfalcon)), open the **Security** tab, and click **Report a vulnerability**. This submits an encrypted, confidential advisory directly to the project maintainers.

### What to Include
To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Python version, operating system, and package version (`logicfalcon --version`).
- Any known remediation or mitigation steps.

### Our Commitment
- We will acknowledge receipt of your report within 48 business hours.
- We will provide an assessment of the vulnerability and expected remediation timeline.
- We will coordinate public disclosure after a fix or mitigation has been published.
